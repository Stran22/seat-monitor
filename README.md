# Мониторинг мест

Универсальная заготовка для проверки доступности мест в системах онлайн-бронирования.

## Безопасность

Исходный код не содержит названий площадок, адресов клиентских сайтов, списков мероприятий, токенов или реквизитов баз данных. Целевые страницы задаются только через защищённые переменные GitHub Actions или локальное окружение. В логах и общедоступных артефактах адреса целей не публикуются.

## Диагностика

На первом этапе проверяется только факт загрузки страницы и наличие встроенного виджета. **Количество свободных и проданных мест не определяется**, пока не подтверждён достоверный источник данных.

Для локального запуска:

```bash
npm install
npx playwright install chromium
MONITOR_TARGETS_JSON='[{"id":"test","url":"https://example.com/"}]' npm run diagnose
```

Переменная `MONITOR_TARGETS_JSON` задаёт не более 100 URL. В публичной автоматизации она должна храниться в секрете `MONITOR_TARGETS_JSON`, а не в репозитории. Для теста на GitHub откройте Actions → Diagnostics → Run workflow (когда секрет будет настроен).

Автоматическая отправка результатов и регулярные проверки намеренно **не включены** до проверки источника мест. Вывод не содержит URL целей и персональных данных.

## Планируемый график

В часовом поясе каждой площадки: две базовые проверки в 01:00 и 06:00, дополнительные проверки с интервалами 11 / 5 / 3 часа по мере приближения события. График будет реализован после проверки способа получения достоверного количества мест.
